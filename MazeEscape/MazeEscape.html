Commands are always written in English.

Every IF and WHILE needs its own END. Indentation helps readability; it does not close a block.

How blocks work · see actual code examples
  • Unlike Python, use END to close a block. Write commands on separate lines, without colons.
  • ELSE belongs to its IF and does not need an additional END.
  • END closes the innermost open block first.

Write IF WALL FRONT, not IF <WALL FRONT>. Replace the whole placeholder with an actual condition.

These examples demonstrate syntax, not a complete maze-solving algorithm.

IF WALL FRONT
  TURN LEFT
ELSE
  MOVE
END

Nested blocks

WHILE WALL FRONT
  IF WALL LEFT
    TURN RIGHT
  ELSE
    TURN LEFT
  END  # closes IF
END    # closes WHILE

    Command reference

    Italic words are placeholders. Replace them with an actual condition, direction, name, or value.

    Actions

    MOVE
    Move one cell forward.
    TURN direction
    Turn 90° toward LEFT or RIGHT.

    Conditions

    WALL direction
    True for a wall at FRONT, LEFT, or RIGHT.
    AT_GOAL
    True after reaching the goal.
    NOT condition
    Invert a condition.
    condition AND / OR condition
    Combine conditions. NOT is evaluated first, then AND, then OR.

    Control flow

    IF condition / ELSE / END
    Run one of two branches based on a condition.
    WHILE condition / END
    Repeat while a condition is true.

    Variables

    SET name TO value
    Set an integer from a number, variable, or variable plus or minus a number.
    name operator value
    Compare a variable with a number or variable using =, !=, <, >, <=, or >=.

    Exploration memory

    MARK
    Mark the current cell as visited.
    UNVISITED direction
    True when the neighboring cell is open and unmarked. Use FRONT, LEFT, RIGHT, or BACK.
    MARKED direction
    Check a neighboring cell's mark using FRONT, LEFT, RIGHT, or BACK.
    PUSH direction
    Remember an absolute direction using FRONT, LEFT, RIGHT, or BACK.
    FACE POP
    Face and remove the latest saved direction.
    STACK EMPTY
    True when no return direction is saved.
