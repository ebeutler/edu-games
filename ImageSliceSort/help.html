Learn how sorting algorithms rebuild a scrambled photograph.

What is Image Slice Sort?

Image Slice Sort turns a photograph into vertical slices, shuffles them, and uses sorting algorithms to restore their original order. It is intended to make comparisons, movements, and differences between algorithms visible rather than presenting sorting as an abstract list of numbers.

Getting started

  1. Choose a photo. Select an image, take a photo on a supported device, or drag an image onto the upload area.
  2. Choose the number of slices. More slices make the image and sorting process more detailed, but slower algorithms take longer.
  3. Choose how many algorithms to show. Run one algorithm, two side by side, or four in a 2 by 2 grid.
  4. Select an algorithm for each sort. Every active algorithm receives an independent copy of the same scrambled arrangement.
  5. Set the speed. The speed controls how many sorting operations each algorithm receives per second.
  6. Start sorting. All active algorithms start together and use the shared controls.

Controls

Start
Starts or resumes every unfinished sort.
Stop
Pauses all active sorts without losing progress.
Step
Advances every unfinished sort by one raw operation.
Reset
Returns every sort to the current shared scramble and clears its statistics.
Reshuffle
Creates a new shared scramble for every active sort.
Full screen
Maximizes the available image area while retaining the controls and statistics.

Color coding

  • Green: slices being compared.
  • Yellow: slices being moved.
  • Purple: the current QuickSort pivot.

When “Show every comparison” is disabled, comparisons are still performed and counted, but their green highlight is hidden. This keeps simultaneous sorts synchronized by raw operations.

Comparing algorithms

All active algorithms use the same image and initial shuffle. Each panel maintains its own comparison count, move count, elapsed time, and state. A completed algorithm stops while the others continue.

The displayed race compares visualization operations, not processor-level execution speed. Different algorithms also define a move in different ways, so the statistics are educational indicators rather than a formal benchmark.

Novelty algorithms

Novelty algorithms are intentionally inefficient and are separated in the algorithm list. Bogosort is limited to 8 slices and Stooge sort to 64 slices to prevent impractically long runs.

Image privacy

Your photo is processed locally inside the browser and is never uploaded. See the data privacy statement for details.
